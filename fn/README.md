# Fuentes de las funciones edge

Copia de trabajo de las funciones que viven en Supabase (proyecto
`rehophywchakfapivsbh`). **La que manda es la desplegada**, no ésta: aquí están
para poder leerlas, revisarlas en un diff y no tener que sacarlas de la consola
cada vez.

Al tocar una, se despliega a Supabase y se actualiza el archivo de aquí en el
mismo commit. Si los dos se separan, gana la desplegada.
